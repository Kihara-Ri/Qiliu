# 右侧面板布局说明

> 适用版本：栖流 1.2.0

## 设计目标

栖流面向长期观看少量固定直播间的桌面用户。画面是第一层；右侧面板只在换源、登录、切换收藏或排障时出现，不能成为需要频繁操作的控制台。

## 信息架构

面板使用单层标签导航，不使用首页或多级菜单：

1. **设置**：直播间链接、复制、粘贴清洗、独立的播放与收藏操作、当前房间信息、画质和线路选择、Bilibili 登录。
2. **收藏**：已保存直播间、当前播放状态、切换和移除。
3. **监控**：实时画质、码率、分辨率、帧率、缓冲、掉帧、线路和连接恢复。
4. **关于**：QN、线路恢复、数据存储、版本、许可和 GitHub 参考项目。

默认每次打开面板都回到“设置”。监控数据仍由播放恢复逻辑使用，但只有进入“监控”时才请求一次即时刷新；用户不需要为了正常播放关注这些数值。

## 内容规则

- 设置页只保留一组紧凑的当前直播间摘要，显示标题、主播、头像和状态，为手动画质/线路切换提供必要上下文。
- 不使用“虎牙 · Bilibili”“当前主播”一类大标题重复上下文。
- 不在底部常驻技术栈或长说明；难懂概念放入“关于”的可展开条目。
- 空状态只说明下一步，并提供一个明确动作。
- 标签支持方向键、Home 和 End；所有按钮保留可见焦点。

## 布局与动画约束

- 面板外壳永久挂载在固定合成图层；收起时只做 `translate3d`，不卸载、不改变宽度。
- 内部视图使用同一网格区域并横向位移；橙色标签指示条在四个等宽位置之间滑动，不切换 `display`。
- 内部视图不得改变视频元素或面板外壳的布局边界。
- 面板宽度上限为 440 px，小窗口使用 `calc(100vw - 24px)` 留出画面边缘。
- 间距只使用 4 px 基础的语义变量；相关内容紧凑分组，不同任务之间留 24–32 px。
- 进入分区只做轻微的 `opacity + transform`；遵守 `prefers-reduced-motion`。
